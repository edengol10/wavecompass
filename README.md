# WaveCompass

WaveCompass is a polished static surf-trip picker. Choose a month, surf level,
budget, and tropical preference, then get a town or surf area recommendation
with background imagery, local wave info, and quick links for photos, maps, and
videos.

## Run Locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit:

```text
http://localhost:8080
```

## Deploy

This site is ready for GitHub Pages because it has no build step.

1. Create a GitHub repository named `wavecompass`.
2. Push this folder.
3. In GitHub, enable Pages from the `main` branch root.
